# 云屿

一个简约风的全栈演示网站，包含用户名密码账号体系、好友与私聊、群聊、朋友圈动态、聊天附件、个人跨设备文件空间，以及直连厂商官方网页版的云游戏大厅。

长期公网部署、持久卷、HTTPS 和上线验收步骤请参阅 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 立即运行

环境要求：Node.js 22.9 或更高版本。

```powershell
npm install
npm start
```

浏览器打开：`http://localhost:3000`

演示账号：

- 用户名：`demo`
- 密码：`Demo123!`

演示数据还包含 `a_cheng`、`ye_zi`、`lin_yi`，密码均为 `Demo123!`，方便测试不同账号之间的好友和消息流程。演示账号仅用于本机体验，正式部署前必须删除或修改。

开发模式（代码变更后自动重启）：

```powershell
npm run dev
```

## 已实现功能

### 账号与登录

- 仅使用用户名和密码注册、登录，不需要邮箱。
- 密码使用 bcrypt 哈希保存，数据库不保存明文密码。
- 会话令牌使用 HttpOnly Cookie 保存，数据库只保存令牌 SHA-256 哈希。
- 网站登录状态保持 30 天，支持同一账号在多台设备分别登录。
- 登录接口限流、同源校验和自定义请求头校验。
- 编辑个人资料：修改昵称（2–30 个字符）和头像颜色（预设色板），好友端实时刷新。

### 好友与聊天

- 按用户名或昵称搜索用户、发送好友请求、接受或忽略请求。
- 好友一对一私聊、创建群聊、查看群成员、群主添加成员。
- Socket.IO 实时消息、在线状态、未读数量、历史消息分页。
- 私聊和群聊内发送文字及文件。
- 同一账号的多台设备可同步接收消息。
- 私聊已读回执：自己最后一条消息显示已读 / 未读状态。
- 正在输入提示：私聊与群聊实时显示「对方正在输入…」。
- 消息撤回：可撤回自己发送的消息，附件一并清理，仅会话内可见权限。
- 群聊管理：群主可移出成员；任何成员可退出群聊，群主退出时自动转让群主，最后一位成员退出后群聊解散。

### 文件传输

- 个人文件上传、列表、下载和删除。
- 同一账号换设备登录后，可下载自己此前上传的文件。
- 聊天附件只有会话成员可以下载。
- 单个文件最大 25 MB，每个账号演示配额 200 MB。
- 文件名随机化保存；下载时校验文件所有权或会话成员权限。
- 已被聊天消息引用的附件不能单独删除，避免聊天记录出现失效链接（随消息撤回删除）。
- 文件空间支持按文件名搜索，并可按「个人文件 / 聊天附件」筛选。

### 朋友圈

- 发布文字动态，或一次附上最多 9 张图片（JPG / PNG / GIF / WebP，单张 5 MB），九宫格展示、点击放大查看。
- 三种可见范围：**好友可见**（默认，按当前好友关系判断）、**仅自己可见**、**站内公开**。解除好友关系后立即不再看到对方的好友动态。
- 动态流按时间倒序展示自己与好友的公开内容，支持「全部 / 好友 / 我的」筛选与分页加载。
- 点赞 / 取消点赞、点赞名单；评论与「回复某人」，动态作者可删除自己动态下的评论。
- 删除自己的动态会级联清理图片文件、点赞与评论。
- 图片地址按动态可见范围单独鉴权，陌生人即使拿到图片 URL 也无法访问；上传目录从不直接暴露。
- 新动态与「别人赞了 / 评论了我的动态」会在导航显示红点，「新消息」弹窗列出互动记录并可标记已读（已读状态存浏览器本地）。
- 发布、点赞、评论通过 Socket.IO 实时同步到在线的相关用户。

## 云游戏接入边界

**能玩，但不能免登，也不能内嵌**——这是厂商的授权与安全策略决定的：

- 米哈游 / 库洛没有向第三方网站开放 OAuth / SSO。云屿的 30 天会话只免除重复登录网站，**不能代替游戏账号登录**。
- 官方页面返回 `X-Frame-Options: DENY`（或等效 CSP），禁止被第三方站点 iframe 嵌入，因此游戏画面在独立标签页运行。云屿不会通过反向代理改写该响应头来绕过限制。
- 免费时长、畅玩卡、排队与画质完全由官方服务控制。

### 自建 / 已授权云游戏服务

如果你拥有自己的 GPU 串流服务或已获授权的服务地址，可以用环境变量替换官方入口。复制 `.env.example` 为 `.env`：

```powershell
Copy-Item -LiteralPath .env.example -Destination .env
```

```dotenv
CLOUD_GENSHIN_URL=https://自建或已授权服务地址
# 仅当该服务允许被嵌入时开启：游戏画面会在站内启动台直接运行
CLOUD_GENSHIN_EMBED=1
# 仅当该服务确实实现了单点登录时开启（不会自动实现 OAuth / SSO）
CLOUD_GENSHIN_SSO=1
```

变量名前缀与游戏对应：`CLOUD_GENSHIN`、`CLOUD_WUTHERING_WAVES`、`CLOUD_STAR_RAIL`、`CLOUD_ZZZ`。地址只允许 HTTPS（本机调试可用 `http://localhost`）；列表接口不会暴露自建服务地址，只能通过启动接口取得。地址缺失或非法时，对应游戏不会启动。

## 跨设备访问

服务默认监听 `0.0.0.0:3000`。在可信局域网内，可让 Windows 防火墙允许 Node.js 或 TCP 3000 端口，然后使用本机局域网 IP 访问：

```text
http://本机局域网IP:3000
```

不同设备仍需分别登录云屿账号；登录后可访问同一账号的会话和文件。不要把演示服务直接暴露到公网。正式部署应使用 HTTPS、受控反向代理、安全 Cookie、备份和日志策略。
